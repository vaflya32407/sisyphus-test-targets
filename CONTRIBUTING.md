# Contributing

## Setup
1. Clone the repository
2. Install dependencies (if any)
3. Run tests/validation steps

## Branching
- `main` is the default branch
- Feature branches: `feat/<short-name>`
- Fix branches: `fix/<short-name>`

## Commit style
Use Conventional Commits:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`
